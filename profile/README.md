## 🔬 实验室介绍<a id="about"></a>

欢迎来到 **CWNU-SmartCar-Lab（西华师范大学智能车实验室）**！

我们成立于 **2022 年**，是一支专注于**智能车、嵌入式系统与机器人技术**的高校工程竞赛与研发团队。自成立以来，团队在全国大学生智能汽车竞赛（含室外赛全国总决赛）、四川省大学生机器人大赛等智能车、嵌入式与机器人赛事中斩获多项国家级与省级奖项。

在这里，代码与硬件碰撞出激情的火花，理论与实践落地于真实的赛道之上。我们围绕以下核心方向持续探索，致力于打破学科壁垒，培养兼具工程落地能力与系统思维的软硬件全栈开发者：

- **🤖 自动驾驶与具身智能**：探索智能体决策、强化学习与自动驾驶算法在移动平台上的应用落地；
- **👁️ 视觉感知与 SLAM 建图**：深耕数字图像处理、OpenCV 视觉算法以及基于 ROS / ROS 2 的激光雷达 SLAM 导航；
- **⚙️ 嵌入式与底层控制**：专注 MCU 驱动架构、多传感器接口、电机闭环控制与线性自抗扰控制（LADRC）等工程算法；
- **🔧 硬件电路与机械结构**：覆盖原理图设计、芯片与器件选型、PCB 布局布线、电路焊接调试及 3D 打印结构制作。

## ⏱️ 招新与考核<a id="recruitment"></a>

想要加入我们，与志同道合的伙伴并肩作战？以下是实验室「新星计划」的考核方向与时间节点：

### 🎯 考核方向与能力要求

| 考核方向 | 能力要求 |
| :---: | :--- |
| **传统嵌入式**<br /><sub>Embedded&nbsp;Systems</sub> | 掌握常用 MCU 外设驱动开发、串口（UART）及其他常见通信协议，具备一定的自动控制理论基础。 |
| **Linux&nbsp;视觉**<br /><sub>Linux&nbsp;&amp;&nbsp;Vision</sub> | 熟悉 Linux 开发环境，掌握数字图像处理基础，能够熟练使用 OpenCV，并对 ROS / ROS 2 系统有一定了解。 |
| **硬件与结构**<br /><sub>Hardware&nbsp;&amp;&nbsp;Mechanics</sub> | 熟悉电路原理图设计、芯片与器件选型、PCB 布局布线、电路焊接与维修，并掌握 3D 打印等基础结构制作技术。 |

### 📅 考核时间线

| 考核阶段 | 时间安排 | 考核目标与通关标准 |
| :---: | :---: | :--- |
| **初试（Phase 1）** | 每年 9 月中旬 | **基础能力**：考察对应方向的基础理论素养与常用开发工具掌握情况。 |
| **终考（Final）** | 每年 10 月底 | **项目实操**：通过完整实践任务检验动手能力、调试排错与工程落地水平。 |

> **💡 提示：** 态度决定高度！相比于现有的技术储备，我们更看重你持续学习的能力、遇到 Bug 时死磕到底的韧性，以及值得信赖的团队协作精神。

## 🤝 致谢与协作<a id="contributing"></a>

一个硬核实验室的成长，离不开每一位成员的全力投入与历代前辈的技术传承：

- **致敬前辈**：感谢每一位曾熬夜看波形、调 PID、焊板子、守在赛道旁的实验室伙伴；
- **致谢开源**：感谢开源社区提供的优秀框架与工具链，让我们得以站在巨人的肩膀上不断探索；
- **内部协作**：组织成员更新代码请遵循 `Feature Branch` 工作流，通过 **Pull Request** 提交改动，并在完成 **Code Review** 后合并；
- **社区交流**：欢迎外部开发者通过 **Issue** 反馈问题与建议，或直接发起 **Pull Request** 共同完善我们的开源项目。
